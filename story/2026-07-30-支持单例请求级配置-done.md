# 支持单例请求级配置

## 背景

`HttpRequestUtils` 已复用单个 Apache HTTP 客户端和连接池，但连接、读取及连接池
获取超时只能通过 `ConnectPool` 在客户端级设置。一个应用使用单例
`HttpRequestUtils` 访问多个远程服务时，无法为每次请求应用独立超时，也无法按
请求关闭重定向。

当前请求执行异常统一包装为 `RuntimeException`，调用方无法判断带正文请求处于
未写出、写出中还是已完整写出的阶段。同步和异步连接池模式还默认信任所有 TLS
证书并关闭主机名校验，安全性低于系统默认 HTTPS 行为。

## 目标

- 支持单例 `HttpRequestUtils` 的请求级超时和重定向配置。
- 暴露请求正文写出阶段，帮助调用方判断失败请求能否安全重试。
- 同步和异步客户端默认使用系统信任库及标准主机名校验。
- 保留现有构造方法、请求方法签名和返回类型，保证历史 API 源码兼容。
- 保留显式启用“不安全信任全部证书”的兼容能力。

## 范围

- 新增不可变请求选项和值校验。
- 新增不会与历史重载产生歧义的请求级配置 API。
- 新增结构化请求执行异常和正文写出状态。
- 调整同步、异步 TLS 默认策略并提供显式兼容开关。
- 固化 `HttpRequestUtils` 构造时取得的连接池配置。
- 补充请求级超时、重定向、写出状态、旧 API 和 TLS 策略测试。
- 更新 README 使用说明和安全说明。
- 将项目版本升级至 `0.1.3`，并安装到本地 Maven 仓库供下游验证。

## 非目标

- 不迁移到 Apache HttpClient 5。
- 不删除或修改历史公开方法签名。
- 不改变原始响应由调用方关闭的约定。
- 不为业务调用定义自动重试或幂等策略。
- 不引入 Spring 或其他容器依赖。
- 不发布 Maven Central 或修改项目版本号。

## 关键设计

- 历史 `httpRequest`、`getRequest`、`postRequest` 等方法保持原签名并继续使用
  客户端默认配置。
- 新增 `httpRequestWithOptions`，通过独立方法名避免与历史可变参数重载在传入
  `null` 时发生编译歧义。
- `HttpRequestOptions` 包含连接超时、读取超时、连接池获取超时和是否允许
  重定向，并在构造时校验。
- 每次请求通过 Apache `RequestConfig` 应用请求选项，不修改共享客户端或
  `ConnectPool`。
- 请求实体使用内部跟踪包装器记录 `NOT_STARTED`、`STARTED`、`COMPLETED`。
- `IOException` 包装为兼容 `RuntimeException` 的
  `HttpRequestExecuteException`，并携带写出状态。
- 默认 TLS 使用系统信任库和标准主机名校验；同步、异步构建器及
  `HttpRequestUtils` 提供命名明确的不安全兼容开关。
- `ConnectPool` 增加复制能力，`HttpRequestUtils` 构造时保存快照，避免延迟
  创建客户端前被外部修改。

## 接口和数据影响

- 新增公开类型：
  - `HttpRequestOptions`
  - `HttpRequestExecuteException`
  - `RequestWriteState`
- 新增 `HttpRequestUtils#httpRequestWithOptions`。
- 新增允许显式启用不安全 TLS 的构造方法和构建器设置方法。
- 历史公开 API 不删除、不改名、不改变参数和返回类型。
- 不涉及数据库、配置文件或外部服务协议。

## 验收标准

- 历史 API 测试继续通过。
- 同一 `HttpRequestUtils` 可对不同请求应用不同超时。
- 禁止重定向时返回原始 3xx，允许重定向时可访问最终响应。
- 连接失败时正文状态为 `NOT_STARTED`。
- 服务端在正文写出后断开时，异常状态不再是 `NOT_STARTED`。
- 无配置连接池和配置连接池均默认执行安全 TLS 校验。
- 不安全 TLS 只能通过新增显式 API 开启。
- 同步、异步客户端和 `HttpRequestUtils` 的资源关闭行为不退化。
- JDK 8 下完整测试和构建通过。

## 风险与阻塞

- 默认 TLS 从不安全信任全部证书调整为系统安全策略后，依赖自签名证书且未正确
  配置信任库的历史环境需要显式使用兼容开关或补充受信任证书。
- 请求正文写出阶段只能描述客户端侧写出进度，不能单独证明服务端是否已处理；
  调用方仍需按业务幂等和状态查询规则处理结果不确定场景。
- `0.1.3` 已安装到当前开发环境的本地 Maven 仓库，尚未发布到远程 Maven
  仓库；其他开发或部署环境仍需按发布流程获取该版本。
- 当前无实现阻塞。
