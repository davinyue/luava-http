# 恢复文件上传测试

## 背景

原文件上传测试依赖 Windows 固定文件和本地外部服务，在连接池修复中被替换，导致 multipart 文件上传覆盖丢失。

## 目标

恢复可重复执行的文件上传测试，不依赖固定文件、操作系统路径或外部服务。

## 范围

- 恢复 `FileUploadTest`。
- 使用临时文件和内嵌 HTTP 服务验证 multipart 请求。
- 验证测试资源均能正常释放。

## 非目标

- 不修改生产环境文件上传实现。
- 不引入新的测试框架或 HTTP 服务依赖。

## 关键设计

测试运行时创建临时文件，由 JDK 内嵌 HTTP 服务接收 multipart 请求，并断言 Content-Type、文件名、文件内容和普通表单字段。

## 验收标准

- 文件上传测试不依赖外部文件和服务。
- multipart 请求内容得到有效断言。
- Maven 测试和打包通过。
